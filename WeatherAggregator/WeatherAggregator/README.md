# Weather Aggregator (C#, .NET 8)

!По непонятным мне причинам, данные по городам подгружаются только с ВПН, по крайней мере с моих устройств, код пробует несколько режимов подключения (без системного прокси,только IPv4,только TLS 1.2, 
новое соединение на каждый запрос, их комбинации). Если консоль не выведет данные по городам без ВПН, попробуйте запустить программу с ним!

Консольное приложение: загружает список городов из файла, для каждого уникального города запрашивает
`https://wttr.in/{City}?format=j1`, выводит город, страну и текущую температуру, затем группирует города
по странам и выводит количество городов, среднюю, минимальную и максимальную температуру.

JSON разбирается встроенным `System.Text.Json`, других пакетов нет. Все значения вычисляются кодом.

## Запуск
1. Положите файл со списком городов из задания рядом с программой под именем `cities.txt`
   (подойдёт любой текстовый формат: города разделены переводом строки, запятой или `;`; пустые строки и строки с `#` игнорируются).
2. `dotnet run -c Release` или запуск из Visual Studio 2022 (`Ctrl+F5`).

Путь к файлу или URL можно передать первым аргументом:
```
WeatherAggregator.exe "C:\data\cities.txt"
WeatherAggregator.exe https://example.com/cities.txt
```

## Пример вывода
```
Tokyo, Japan +18 °C
Osaka, Japan +16 °C

Japan — 2 cities, avg: +17 °C, min: +16 °C, max: +18 °C
```
Если часть городов получить не удалось, они перечисляются в конце с причиной (таймаут, HTTP-код, ошибка TLS и т.д.).

Код возврата: `0` — всё получено, `3` — получена только часть городов, `2` — ничего не получено, `1` — не удалось загрузить список.

## Диагностика ошибок
Ход работы печатается в stderr (`[3/9] Moscow: ok`), результаты — в stdout. Для каждого города с ошибкой показывается причина:
таймаут, код HTTP **вместе с началом текста ответа сервера**, ошибка TLS-сертификата и т.д.

Если не получен ни один город, программа делает контрольный запрос для `Moscow` и подсказывает, где проблема:
в названиях городов из файла, в самом сервисе wttr.in (недоступен или ограничивает запросы с вашего адреса) или в сети.

Проверка TLS-сертификата не отключается.
