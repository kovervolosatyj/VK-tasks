# VK-tasks
Решения выполнены на языке C# (.NET 8) в виде консольных приложений.

**Структура:**
<p><b>WukongBenchmark</b>: скрипт автоматизации запуска и настройки Black Myth: Wukong Benchmark Tool.</p>
<p><b>WeatherAggregator</b>: консольный агрегатор погодных данных по городам через API wttr.in.</p>

Более конкретное описание работы каждого приложения есть в одноименных папках.
