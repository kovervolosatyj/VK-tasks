# VK-tasks
Решения выполнены на языке C# (.NET 8) в виде консольных приложений.

**Структура:**
WukongBenchmark — Скрипт автоматизации запуска и настройки Black Myth: Wukong Benchmark Tool.
WeatherAggregator — Консольный агрегатор погодных данных по городам через API wttr.in.

Более конкретное описание работы каждого приложения есть в одноименных папках.
